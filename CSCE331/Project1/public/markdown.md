1. Section headings (do not need to implement the table of contents).
  # first level
  ## second level
  ### third level
2. Styling text
  **BOLD** 
  _ITALIC_
  <ins>UNDERLINED</ins>

3. Links
  [ Name ]( url ) 
4. Images
  ![ alt text ]( url )
5. Unordered lists (no need to go below 2 levels)
  * first item
    * nested item
  * second item
  * third item
6. Ordered lists (no need to go below 2 levels): Note - you can say 1. 2. 3. but the style below is easier to maintain. 
    1. first item
        - first nested item
        - second nested item
    2. second item
    3. third item
7. Paragraph break: blank line
